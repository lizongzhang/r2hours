1 导入思路

  • 先用Import Dataset按钮导入导入

  • 再将history生成的代码发送到代码文件中

  • 避免文件路径输入错误导致代码报错（如C:/Users/xxx/Desktop/stroke.xlsx）

2 使用Import Dataset按钮导入

  • 创建项目

  • 将要导入的数据文件放在当前工作目录下，点击Import Dataset按钮，选择文件类型（如 Excel、CSV、txt）。

  • 在弹出的界面中选择文件并设置相关选项，最后点击Import完成导入。

关键参数

  • Sheet：选择要导入的工作表（默认是第一个 sheet）

  • Name：给导入的数据框起一个名字（推荐使用df）

  • Skip：如果 Excel 前几行是标题或说明，填写要跳过的行数

  • First Row as Names：一般保持勾选（把第一行当作列名）

  • Preview：下方可以实时预览数据是否正确

3 直接用 R 代码导入数据

导入Excel文件

library(readxl)

df <- read_xlsx("stroke.xlsx")

df <- read_xlsx("stroke.xlsx",
                 sheet = 1,           # 导入第几个工作表
                 skip = 0,            # 跳过前几行
                 col_names = TRUE)    # 第一行作为变量名

导入csv文件

#使用 tidyverse 推荐方式（更快、更现代）
library(readr)
df <- read_csv("stroke.csv")

# 基础 R 函数
df <- read.csv("stroke.csv")

导入txt文件

# 分号分隔
df <- read_delim("stroke.txt", delim = ";")

# 空格分隔
# df <- read_delim("stroke.txt", delim = " ")

4常见报错

如果您遇到以下情况，很可能就是中文路径/文件名的问题：

  • Error: ... does not exist in current working directory.

  • Error in gzfile(file, "rb") : cannot open the connection

解决方案：重命名文件和路径，避免使用中文

保证代码的可移植性（即在别人的电脑上也能跑通）

  • 文件名统一使用英文、数字或下划线（例如：stroke_data.xlsx 而不是 中风数据.xlsx）。

  • 避免中文路径：项目所在的文件夹层级中也尽量不要出现中文。
