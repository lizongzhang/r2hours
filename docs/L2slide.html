1 R与RStudio 的关系

  • R：底层的计算引擎

    • 负责所有数据处理、统计分析和图形绘制的核心计算。

    • 界面简陋（纯命令行），对人类极其不友好。

  • RStudio：豪华的仪表盘 (IDE)

    • 它是 R 的集成开发环境 (Integrated Development Environment)。

    • 提供代码高亮、对象查看、图形预览、一键导出等可视化操作。

下载安装文件

  • R安装文件
    • https://cran.r-project.org/
  • RStudio 安装文件
    • https://posit.co/download/rstudio-desktop

安装顺序

  • 先装 R，后装 RStudio，不可颠倒。

  • 日常写代码，只需要打开 RStudio，让底层的 R 默默工作即可。

2 安装前最致命的“排雷”

Windows 用户的头号杀手：中文路径

绝对不要把 R 或 RStudio 安装在包含中文的文件夹下！ 如果您的 Windows 电脑用户名是中文（如 C:\Users\张三），日后在安装高阶 R 包时，极易遭遇无法解析的乱码报错。

  • 解决方案（Windows）

    • 保持默认安装路径（通常是 C:\Program Files\R）。

    • 确保系统用户名纯英文。如果已经是中文，建议更改环境变量或新建英文账户。

  • 解决方案（macOS）

    • 无中文路径困扰，直接一路“继续”即可。

3 系统的编译环境

  • 为什么别人的代码能跑，我的会报错？

    • 许多高级 R 包（如涉及复杂统计模型的包）包含由 C++ 或 Fortran 编写的底层源代码，需要您的电脑具备编译环境才能进行构建与安装。

  • Windows 用户需要安装：Rtools

    • Rtools不是 R 包，而是一个专门为 Windows 打造的开发工具链（Toolchain）。

    • Rtools一个独立的软件，必须前往 CRAN 官网单独下载并安装，否则无法编译含有底层代码的 R 包

    • https://cran.r-project.org/bin/windows/Rtools/

    • 注意：安装过程中建议保持默认路径，且不要在路径中使用空格或中文字符。

  • macOS 用户必备：Xcode Command Line Tools

    • 打开 Mac 终端 (Terminal)，输入 xcode-select --install 回车。

    • 苹果系统的原生开发者工具箱

4 全局设置

  • R 的官方仓库 (CRAN)服务器在国外。如果不做配置，安装大体积R包时极易因超时而中断。

  • 解决方案：将下载通道切换至国内大学（如清华、中科大）的镜像站。

# 这是一个模拟报错的展示
> install.packages("ggplot2")

[错误提示如下]
Warning: Timeout of 60 seconds was reached
Error: download of package 'ggplot2' failed

  • RStudio 中的全局设置

    • 路径：Tools -> Global Options -> Packages

    • 点击 Change...，选择离你最近的 China 节点，点击 Apply。

  • 配置路径

    • 路径：Tools -> Global Options -> General -> Basic

  • 关键选项修改

    • 取消勾选：Restore .RData into workspace at startup（启动时不恢复旧数据）。

    • 设置选项：Save workspace to .RData on exit 改为 Never（退出时绝不保存）。
