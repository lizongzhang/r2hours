1 代码不执行——只按了 Enter

赋值符号 <-

在 R 中，给对象赋值使用 <-，而不是 =。
<- 由”小于号”和”减号”组成，推荐用快捷键一次打出：

操作系统 赋值符号快捷键
Windows Alt + -
Mac Option + - 
apple <- 5
banana <- 10

执行后，右上角 Environment 面板会出现 apple = 5 和 banana = 10，说明赋值成功。

计算与保存结果

# 直接计算，结果只显示在Console，不会被保存
apple + banana
[1] 15
# 保存结果，需要赋值给一个新对象
total <- apple + banana
total
[1] 15
Tip

判断代码有没有执行成功：
查看 Environment 面板，赋值语句执行后对象会出现在列表中。
若只是计算（没有赋值），结果仅显示在 Console，不会保存。

Tip

写完代码直接按 Enter，代码不会执行，光标只是跳到下一行。 正确做法**：必须按 Ctrl + Enter（Mac：Command + Enter）才能执行当前行。

操作系统 执行代码快捷键
Windows Ctrl + Enter
Mac Command + Enter

执行成功后，Console制台会以蓝色字体再显示一次刚才执行的代码，并输出结果。

# 将光标放在这行，按 Ctrl+Enter 执行
banana <- 10

2 报错”找不到对象”——代码顺序错了

Error: object 'price' not found

原因：调用了一个还没有赋值的对象。R 按顺序执行代码，必须先赋值，才能使用。

# ❌ 错误示范：price 还没赋值，直接使用
# price * 0.8
# ✅ 正确：先赋值，再使用
price <- 100    # 第12行：先执行这行
price * 0.8     # 第14行：再执行这行
[1] 80
Tip

排查”找不到对象”的方法：
查看 Environment 面板，如果该对象不在列表中，说明赋值代码还没有被执行。
需要先运行赋值语句，再运行使用该对象的代码。

3 大小写不通用

R 严格区分大小写，price 和 Price 是两个完全不同的对象。

price <- 100

# ✅ 正确：小写 price
price * 0.8      # 输出 80
[1] 80
# ❌ 错误：Price 首字母大写，找不到
# Price * 0.8      # Error: object 'Price' not found
Warning

变量名、函数名，一个字母的大小写差别就会报错。养成习惯，命名时保持一致。

4 输入法陷阱——中文标点

  • R 中所有标点符号（括号、逗号、引号等）必须在英文输入法状态下输入。

  • 中文标点和英文标点外形相似，但 R 无法识别中文标点。

# ✅ 正确：英文逗号
round(pi, 5)     # 输出 3.14159
[1] 3.14159
# ❌ 错误：中文逗号（，）
# round(pi，5)   # Error: unexpected input in "round(pi，"
Tip

中英文标点对比：

标点 英文（✅） 中文（❌）
逗号 , ，
括号 () （）
引号 "" ""

建议写代码时全程保持英文输入法。

报错信息：

Error: unexpected input in "round(pi, "

5 控制台出现 + 号——代码没写完

什么情况会出现 +？

当你在 Source 窗口写了一行未完成的代码（例如只写了 8 + 10 +，后面的数字还没有输入），就按了 Ctrl + Enter，Console 的提示符会从 > 变成 +：

> 8 + 10 +
+

这个 + 表示 R 认为你的代码还没有结束，正在等待后续输入。

+ 状态的危险

如果这时继续运行其他代码，新代码会被当作前面未完成代码的延续，产生意外结果：

> 8 + 10 +
+ round(pi, 3)   # 这里的结果会被拼接进去
[1] 21.142       # 不是你想要的结果

解决方法

Tip

Console 出现 + 时，按 Esc 键退出等待状态，提示符恢复为 >，再重新输入完整的代码。

> 8 + 10 +
+              ← 按 Esc
>              ← 恢复正常，可以重新输入

Source 窗口 vs Console 控制台

RStudio 有两个地方可以输入代码，用途完全不同：

Source 窗口（左上） Console 控制台（左下）
执行方式 Ctrl + Enter 直接按 Enter
代码能否保存 ✅ 保存为 .R 文件 ❌ 关闭后消失
推荐用途 ✅ 正式写代码 临时测试、快速计算
Tip

所有正式代码都应写在 Source 窗口。
Console 只用于临时尝试，关闭 RStudio 后 Console 中的内容无法恢复。

# Win: Alt + -

# ── 执行代码快捷键 ──────────────────────────
# Win: Ctrl + Enter
# Mac: Command + Enter

# ── 赋值示例 ───────────────────────
apple  <- 5
banana <- 10

# ── 计算：结果不保存 ─────────────────────────
apple + banana         # 输出 15，但未保存

# ── 计算：结果保存 ──────────────────────────

total                  # 输出 15

# ── 坑2：先赋值，再使用 ──────────────────────
price <- 100           # 第一步：赋值
price * 0.8            # 第二步：使用，输出 80

# ── 坑3：大小写区分 ──────────────────────────
price * 0.8            # ✅ 正确
# Price * 0.8          # ❌ 报错：object 'Price' not found

# ── 坑4：英文标点 ────────────────────────────

# round(pi，5)         # ❌ 中文逗号，报错

# ── 坑5：未完成代码导致Console出现"+" ──────────
# 8 + 10 +             # ← 写了这行就 Ctrl+Enter，Console 会出现 +
#                        按 Esc 键退出，再重新写完整的代码
8 + 10 + 5             # ✅ 写完整再执行

## [1] 15

## [1] 80

6 总结

# 错误 原因 解决方法
1 代码不执行 只按了 Enter 改用 Ctrl + Enter
2 找不到对象 对象还没赋值就使用 先执行赋值语句，再使用
3 大小写报错 R 严格区分大小写 保持变量名大小写一致
4 标点报错 误用了中文标点 全程保持英文输入法
5 Console 出现 + 代码未写完就执行 按 Esc 退出后重新写
