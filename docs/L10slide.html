1 什么是 NA？

  • NA（Not Available）是 R 中表示缺失值的专用符号。

  • 它不是数字 0，不是空字符串 ""，也不是 NULL，它代表”这个值本来应该有，但我们不知道它是什么”。

  • 现实数据中，NA 几乎无处不在：问卷漏填、仪器故障、数据录入错误

# NA 有不同的"类型"，但通常统一写作 NA
NA          # 逻辑型 NA（默认）
[1] NA
NA_real_    # 数值型 NA
[1] NA
NA_integer_ # 整数型 NA
[1] NA
NA_character_ # 字符型 NA
[1] NA
# NA 的类型判断
is.na(NA)
[1] TRUE

3 检测 NA

is.na() — 逐元素判断是否为 NA

# 对整个数据框，返回同形状的逻辑矩阵

[2,] FALSE  TRUE FALSE  FALSE
[3,] FALSE FALSE  TRUE   TRUE
[4,] FALSE FALSE FALSE  FALSE
[5,] FALSE  TRUE FALSE  FALSE
[6,] FALSE FALSE FALSE  FALSE
[7,] FALSE FALSE FALSE  FALSE

统计每列有多少个 NA

# colSums() 对逻辑矩阵按列求和，TRUE 计为 1
colSums(is.na(df))
  name    age  score passed 
     0      2      1      1

统计每行有多少个 NA

rowSums(is.na(df))
[1] 0 1 2 0 1 0 0

快速查看整体缺失情况

# 缺失值总数
sum(is.na(df))
[1] 4
# 缺失值比例（按列）
colMeans(is.na(df))
     name       age     score    passed 
0.0000000 0.2857143 0.1428571 0.1428571

Tip

colMeans(is.na(df))是一行代码摸清每列缺失率的常用技巧。

4 NA让计算结果报错

均值、求和等聚合函数返回 NA

# age 列含有 NA，mean() 直接返回 NA
mean(df$age)
[1] NA
sum(df$age)
[1] NA
max(df$age)
[1] NA
min(df$age)
[1] NA

Tip

这不是报错，R 正常运行了，但结果是 NA初学者常以为代码写错了，其实是数据中存在缺失值。

解决方法：加上 na.rm = TRUE

# na.rm = TRUE 表示"计算前先忽略 NA"
mean(df$age,  na.rm = TRUE)
[1] 24
sum(df$age,   na.rm = TRUE)
[1] 120
max(df$age,   na.rm = TRUE)
[1] 28

Tip

na.rm 是 NA remove的缩写，几乎所有数值聚合函数都支持这个参数：mean() sum() max() min() sd() var() median() range() ……

Tip

永远不能用 x == NA 判断某个值是否缺失，必须用 is.na(x)！

x <- NA
x == NA    # 错误：返回 NA，不是 TRUE
[1] NA
is.na(x)   # 正确：返回 TRUE
[1] TRUE

cor() 相关系数矩阵报错

# 含 NA 的列直接计算相关系数，返回 NA
cor(df$age, df$score)
[1] NA
# 解决方法：指定 use 参数
cor(df$age, df$score, use = "complete.obs")
[1] 0.6580833

Tip

use = "complete.obs"表示只用两列都不缺失的行来计算。

线性回归 lm() 默认删除含 NA 的行

# lm() 不报错，但会自动删掉含 NA 的行
model <- lm(score ~ age, data = df)

which() 与 NA 的陷阱

# 想找 age > 21 的行号
which(df$age > 21)
[1] 1 3 6 7
# which() 会自动忽略 NA，不报错
# 但筛选时如果直接用逻辑向量，NA 会被保留为"不确定行"
df[df$age > 21, ]       # 含 NA 行也会出现（以 NA 行形式）
     name age score passed
1    张三  22  88.5   TRUE
NA   <NA>  NA    NA     NA
3    王五  25    NA     NA
NA.1 <NA>  NA    NA     NA
6    周九  28  91.0   TRUE
7    吴十  24  78.5   TRUE

用 which() 避免 NA 行混入结果

# 正确写法：用 which() 避免 NA 行混入结果
df[which(df$age > 21), ]
  name age score passed
1 张三  22  88.5   TRUE
3 王五  25    NA     NA
6 周九  28  91.0   TRUE
7 吴十  24  78.5   TRUE

4 处理 NA 的常用方法

方法1：删除含 NA 的行 — na.omit()

# 删除任意列含 NA 的行
df_clean <- na.omit(df)
df_clean
  name age score passed
1 张三  22  88.5   TRUE
4 赵六  21  55.5  FALSE
6 周九  28  91.0   TRUE
7 吴十  24  78.5   TRUE

⚠️ na.omit() 只要某行任意一列有 NA，就整行删除。
数据列多时可能损失大量样本，需谨慎使用。

方法2：只删除特定列含 NA 的行

# 只删除 age 列为 NA 的行
df_age_clean <- df[!is.na(df$age), ]
df_age_clean
  name age score passed
1 张三  22  88.5   TRUE
3 王五  25    NA     NA
4 赵六  21  55.5  FALSE
6 周九  28  91.0   TRUE
7 吴十  24  78.5   TRUE
# 同时要求 age 和 score 都不缺失
df_both_clean <- df[!is.na(df$age) & !is.na(df$score), ]
df_both_clean
  name age score passed
1 张三  22  88.5   TRUE
4 赵六  21  55.5  FALSE
6 周九  28  91.0   TRUE
7 吴十  24  78.5   TRUE

方法3：用指定值填补 NA — replace()

# 用均值填补 age 列的 NA（均值插补）
age_mean <- mean(df$age, na.rm = TRUE)

df$age_filled <- replace(df$age, is.na(df$age), age_mean)

df[, c("age", "age_filled")]
  age age_filled
1  22         22
2  NA         24
3  25         25
4  21         21
5  NA         24
6  28         28
7  24         24

方法4：用 ifelse() 填补

# 将 score 列的 NA 填补为 0
df$score_filled <- ifelse(is.na(df$score), 0, df$score)

df[, c("score", "score_filled")]
  score score_filled
1  88.5         88.5
2  92.0         92.0
3    NA          0.0
4  55.5         55.5
5  85.0         85.0
6  91.0         91.0
7  78.5         78.5

方法5：complete.cases() — 筛选完整行

# 返回每行是否"完整"（无任何 NA）的逻辑向量
complete.cases(df)
[1]  TRUE FALSE FALSE  TRUE FALSE  TRUE  TRUE
# 用于筛选完整行（等价于 na.omit，但更灵活）
df[complete.cases(df), ]
  name age score passed age_filled score_filled
1 张三  22  88.5   TRUE         22         88.5
4 赵六  21  55.5  FALSE         21         55.5
6 周九  28  91.0   TRUE         28         91.0
7 吴十  24  78.5   TRUE         24         78.5
# 也可以只针对某几列判断完整性
df[complete.cases(df[, c("age", "score")]), ]
  name age score passed age_filled score_filled
1 张三  22  88.5   TRUE         22         88.5
4 赵六  21  55.5  FALSE         21         55.5
6 周九  28  91.0   TRUE         28         91.0
7 吴十  24  78.5   TRUE         24         78.5

6 小结

遇到 NA 时

① 检测  →  is.na() / colSums(is.na()) / summary()
② 定位  →  哪些列？缺多少？什么规律？
③ 决策  →  删除？填补？保留？
④ 处理  →  na.omit() / !is.na() / replace() / ifelse()
⑤ 验证  →  再次运行 colSums(is.na()) 确认处理结果
