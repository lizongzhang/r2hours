1 什么是管道符？

  • 管道符 pipe operator: |>把左边的结果自动传递给右边函数的第一个参数。

  • 管道符快捷键

    • Win: shift + control + M

    • macOS: Cmd + Shift + M

# 没有管道符：从内到外嵌套，要从右往左读
round(mean(sqrt(mtcars$hp)), 2)
[1] 11.8
# 有管道符：从左到右，像在读一个步骤清单
mtcars$hp |> sqrt() |> mean() |> round(2)
[1] 11.8

x |> f() 等价于 f(x)
x |> f() |> g() 等价于 g(f(x))

2 为什么用管道符？

不用管道符，多步操作只能靠嵌套或中间变量：

# 嵌套写法：层层包裹，阅读困难
result1 <- round(mean(mtcars$hp), 1)
# 中间变量写法：代码冗长
hp_mean  <- mean(mtcars$hp)
result2  <- round(hp_mean, 1)
result1
[1] 146.7
result2
[1] 146.7

用管道符，步骤清晰，从上到下、从左到右地读：

# 管道符写法：每一步做什么，一目了然
result <- mtcars$hp |> mean() |> round(1)
result
[1] 146.7
Tip

代码要让人读懂，不只是让机器执行。
管道符让代码的逻辑顺序与书写顺序保持一致。

3 |> 和 %>% 的区别

# |>  是 R 4.1+ 内置的原生管道符，无需加载任何包
mtcars$hp |> mean() |> round(1)
[1] 146.7
# %>% 来自 magrittr 包，加载 dplyr 或 tidyverse 后可用
# 两者在绝大多数场景下效果完全相同
mtcars$hp %>% mean() %>% round(1)
[1] 146.7
Tip

💡 推荐初学者统一使用 |>，不需要额外加载包。

  • 默认情况下，RStudio中的管道符对应的是 %>%。

  • 如果你想使用 R 4.1+ 的原生管道符 |>，需要按以下步骤设置：

    • 点击菜单栏的 Tools -> Global Options…

    • 在左侧选择 Code。

    • 在 Editing 选项卡中，找到并勾选：

      • “Use native pipe operator, |> (requires R 4.1+)”

      • 点击 OK。

      • 设置完成后，再次按下 Ctrl/Cmd + Shift + M，就会自动输入 |> 了

重新编码：mutate() + case_when()

case_when() 是 ifelse() 的升级版，可以处理多个条件。

# 将连续的 mpg 重新编码为"低/中/高"油耗分组
mtcars |>
  mutate(
    mpg_group = case_when(
      mpg < 18             ~ "低油耗",
      mpg >= 18 & mpg < 25 ~ "中油耗",
      mpg >= 25            ~ "高油耗"
    )
  ) |>
  select(mpg, mpg_group) |>
  head(8)
                   mpg mpg_group
Mazda RX4         21.0    中油耗
Mazda RX4 Wag     21.0    中油耗
Datsun 710        22.8    中油耗
Hornet 4 Drive    21.4    中油耗
Hornet Sportabout 18.7    中油耗
Valiant           18.1    中油耗
Duster 360        14.3    低油耗
Merc 240D         24.4    中油耗
# 将 am（0/1）重新编码为有意义的标签
mtcars |>
  mutate(
    am_label = case_when(
      am == 0 ~ "自动挡",
      am == 1 ~ "手动挡"
    )
  ) |>
  select(am, am_label) |>
  head(8)
                  am am_label
Mazda RX4          1   手动挡
Mazda RX4 Wag      1   手动挡
Datsun 710         1   手动挡
Hornet 4 Drive     0   自动挡
Hornet Sportabout  0   自动挡
Valiant            0   自动挡
Duster 360         0   自动挡
Merc 240D          0   自动挡

case_when() 的语法：条件 ~ "赋值"，从上到下逐条匹配，匹配到第一个成立的条件就停止。

分组汇总：group_by() + summarise()

# 按气缸数分组，计算各组的平均油耗和平均马力
mtcars |>
  group_by(cyl) |>
  summarise(
    n        = n(),
    mpg_mean = mean(mpg)  |> round(1),
    hp_mean  = mean(hp)   |> round(1)
  )

5 串联所有的步骤

管道符真正的价值在于把多个步骤一气呵成地串联：

# 目标：找出手动挡车中，各气缸数的平均油耗（从高到低排列）
mtcars |>
  filter(am == 1) |>                          # 第1步：只保留手动挡
  mutate(cyl = factor(cyl)) |>               # 第2步：气缸数转为因子
  group_by(cyl) |>                           # 第3步：按气缸数分组
  summarise(
    n        = n(),
    mpg_mean = mean(mpg) |> round(1)         # 第4步：计算平均油耗
  ) |>
  arrange(desc(mpg_mean))                    # 第5步：从高到低排列
# A tibble: 3 × 3
  cyl       n mpg_mean
  <fct> <int>    <dbl>
1 4         8     28.1
2 6         3     20.6
3 8         2     15.4
Tip

如何写好管道符代码

  • 每个 |> 后换行，保持一步一行的格式
  • 用缩进对齐，让结构清晰
  • 每一行加注释说明这一步做什么
  • 中间可以随时插入 head() 或 str() 检查结果

常见报错

报错1：管道符后忘记写函数

# 管道符后面必须接一个函数，不能接数据框
mtcars |> cyl
Error in cyl: The pipe operator requires a function call as RHS (<input>:2:11)

# group_by() 本身不改变数据，只是"打了标记"
# 忘记接 summarise()，数据看起来没有变化
mtcars |>
  group_by(cyl) |>
  head(3)         # 看起来正常，但其实还带着分组标记

6 小结

函数 用途
filter() 按条件筛选行
select() 选择保留的列
mutate() 追加新列或修改已有列
case_when() 多条件重新编码（配合 mutate() 使用）
arrange() 按某列排序（desc() 降序）
group_by() 按变量分组
summarise() 对每组计算汇总统计量
ungroup() 清除分组标记
Warning

  1. |> 后面必须接函数，每步换行，保持代码可读性

  2. case_when() 从上到下逐条匹配，
    条件之间有重叠时，顺序很重要

  3. group_by() 之后记得 summarise() 或 ungroup()，
    否则分组标记会悄悄影响后续所有操作
