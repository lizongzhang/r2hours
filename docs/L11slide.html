1 字符串 vs 因子

字符串 character 因子 factor
用途 自由文本、不固定的内容 有限的固定类别
图表类别顺序 按字母顺序，不可控 由 levels 定义，可控
回归分析 参照组不可控 可手动指定参照组

2 什么时候需要转成因子？

Tip

变量的取值是有限的固定类别，且需要控制类别顺序、
用于绘图或回归分析时，就应该转成因子。

  • ✅ class（车型）：绘图时希望 x 轴按我们定义的顺序排列

  • ✅ drv（驱动方式）：回归时需要明确指定哪种驱动方式为参照组

3 创建因子

factor()

# 将 class 转为因子class_f, 并追加到mpg数据框中
mpg$class_f <- factor(mpg$class)
# 因子的level的排序，默认按字母顺序排
levels(mpg$class_f)
[1] "2seater"    "compact"    "midsize"    "minivan"    "pickup"    
[6] "subcompact" "suv"

levels =

# 将 drv转为因子，按照油耗由低到高，手动指定levels 顺序和标签
mpg$drv_f <- factor(mpg$drv,levels = c("f", "r", "4"),
                    labels = c("front", "rear", "4-wheel"))
levels(mpg$drv_f)
[1] "front"   "rear"    "4-wheel"
table(mpg$drv_f)

  front    rear 4-wheel 
    106      25     103
  • levels 控制类别的顺序，labels 控制类别的显示名称。

4 因子用于绘图：控制类别顺序

查看R代码 
# 字符串：x 轴按字母顺序，类别顺序混乱
boxplot(hwy ~ drv, data = mpg,
        col = c("#8DA0CB", "#FC8D62", "#66C2A5"))
# 因子：x 轴按 levels 定义的顺序（前驱 → 后驱 → 四驱）
boxplot(hwy ~ drv_f, data = mpg,
        col = c("#8DA0CB", "#FC8D62", "#66C2A5"))

5 因子用于回归：控制参照组

# drv 为字符串时：参照组由字母顺序决定
# "4" 字母排最前，自动成为参照组
model1 <- lm(hwy ~ drv, data = mpg)
summary(model1)$coefficients
             Estimate Std. Error   t value      Pr(>|t|)
(Intercept) 19.174757  0.4036737 47.500634 3.396345e-121
drvf         8.985620  0.5668272 15.852486  8.578919e-39
drvr         1.825243  0.9134093  1.998275  4.685929e-02

字符串的levels的排序是由字母顺序决定的，参照组是不可控的。

# drv_f 为因子时：levels 第一个元素"前驱"为参照组
model2 <- lm(hwy ~ drv_f, data = mpg)
summary(model2)$coefficients
              Estimate Std. Error    t value      Pr(>|t|)
(Intercept)  28.160377  0.3979203  70.768881 1.416181e-158
drv_frear    -7.160377  0.9108813  -7.860934  1.445327e-13
drv_f4-wheel -8.985620  0.5668272 -15.852486  8.578919e-39

因子的levels可以自定义参照组。

系数: 后驱 / 四驱 相对于前驱的高速油耗差异（mpg）。

5 forcats 包

  • forcats 是tidyverse中专门处理因子的包。

  • 提供了一系列以 fct_ 开头的函数，比 base R 更简洁直观。

fct_reorder() — 按另一个变量的值排序

# 按各车型高速油耗的中位数，从低到高排列 class
mpg$class_f <- fct_reorder(mpg$class_f, mpg$hwy, median)
levels(mpg$class_f)
[1] "pickup"     "suv"        "minivan"    "2seater"    "subcompact"
[6] "compact"    "midsize"   
table(mpg$class_f)

    pickup        suv    minivan    2seater subcompact    compact    midsize 
        33         62         11          5         35         47         41

因子 class_f：x 轴按油耗中位数从低到高排列

boxplot(hwy ~ class_f, data = mpg,

# 排序后绘图，类别顺序直接反映油耗高低，一目了然
ggplot(mpg, aes(x = class_f, y = hwy)) +
  geom_boxplot(aes(fill = class_f)) +
  theme_minimal()

fct_rev() — 反转类别顺序

# 反转顺序（从高到低）
mpg$class_f_rev <- fct_rev(mpg$class_f)
levels(mpg$class_f_rev)
[1] "midsize"    "compact"    "subcompact" "2seater"    "minivan"   
[6] "suv"        "pickup"
查看R代码 
# 水平翻转后，最高油耗的车型显示在最右侧，便于阅读
par(mar = c(4, 7, 3, 1))          # 扩大左边距，避免标签被截断
boxplot(hwy ~ class_f_rev, data = mpg,
        main   = "fct_rev()：反转后高油耗排最右",
        xlab   = "高速油耗 (mpg)",
        ylab   = "",
        col    = rainbow(7),
        horizontal = TRUE,         # 水平翻转，等价于 coord_flip()
        las    = 1)

7 小结

函数 用途
factor(x, levels=..., labels=...) 创建因子，指定顺序和标签
fct_relevel() 手动将指定类别移到最前
fct_reorder() 按另一个变量的值排序
fct_rev() 反转类别顺序
fct_recode() 重命名类别标签
fct_lump_n() 保留前 n 个高频类别，其余合并为 Other
fct_drop() 删除无数据的类别
levels() 查看类别
relevel() 更改回归参照组（base R）
